# Datastar 1.0.2 → 1.0.4 Integration

Date: 2026-09-21

Vendored runtime bumped from 1.0.2 to 1.0.4 in one step (1.0.3 is subsumed; the
three signal-ordering code paths StarHTML depends on — proxy auto-create,
`__ifmissing` merge, markup-order attribute loop — are byte-identical across
1.0.2/1.0.3/1.0.4). Each upstream changelog item was checked against StarHTML's
surface and decided individually below.

## Patch pipeline

1.0.4 aliases `document` to a minified local (`p=document`). Both patches
(`shadow-dom-scan`, `outside-race-fix`) anchored on the literal `document`, so
they now capture the alias (`«doc»`) and the outside-handler parameter name
(`«arg»`) from their landmarks. The re-anchored definitions apply cleanly to
both the 1.0.2 and 1.0.4 bundles (regression-checked), and
`verify_datastar_patches.py` passes on the built core.

## Test evidence

- Unit: 1,4xx passed; the same 8 pre-existing failures as before the bump (7
  devtools tests need `starelements`, 1 flaky key-file test).
- Integration: all pass.
- Browser (Chromium): migration + compatibility suites pass, including the
  shadow-root scan, persist prehydrate, outside-click race, data-bind seeding,
  SSE patch-elements, and the new QUERY and CSP tests.
- Browser (Firefox, WebKit): the migration suite passes on both via `STARHTML_BROWSER`.
- `tests/browser/test_browser_compatibility.py` used to hang forever: its class-scoped
  async fixture and the function-scoped tests ran on different pytest-asyncio event loops.
  Fixed with `loop_scope="class"`; the suite now runs (7 pass), which exposed a misspelled
  Playwright API (`touch_screen`) and a scroll test that can never pass because the harness
  inlines the ES-module plugin as a classic script (now a strict xfail with that reason).

## Review outcomes (2026-09-21, two independent sub-agent passes)

Commit review: no correctness bugs; hardened patch locals (`_`-prefixed, `reserved` collision guard),
`\1` backreference in the `arg` capture, `Client.query`, wider retry window in the five `*_rebuilds_*`
tests, README retry section rewritten, WASM `handle_request` forwards bodies for all `_BODY_METHODS`.
Changelog audit (28 upstream commits, not just release notes): 24 items checked; the only miss was the
view-transition selector semantics above. Non-note items confirmed harmless: expression escape-marker
removal, `${}` action rewriting, `createError` return type (no plugin uses `ctx.error`), consts aliases
(handled by the captures), signal-delete `null` patches (persist uses `effect`+`getPath`), peek sub-stack,
`datastar-fetch` detail shape unchanged for devtools.
